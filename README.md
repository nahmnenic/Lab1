# Лабораторная работа №1

**Вариант 27:** сотрудники компании.

## Описание

Программа предназначена для учета сотрудников компании.

Реализованы:
- добавление, поиск, изменение и удаление сотрудников;
- обработка исключений;
- сохранение и загрузка данных в JSON;
- сохранение и загрузка данных в XML.
